Begriffe

Lege die möglichen Definitionen in den passenden Begriff ab. Du kannst die Karten jederzeit zwischen den Begriffen verschieben oder zurück in den rechten Bereich legen.

Mögliche Definitionen

Vier Definitionen passen, vier sind falsch. Ziehe sie nach links in einen Begriff.

Klasse

Ein Bauplan, der beschreibt, welche Eigenschaften und Aktionen Objekte dieser Klasse haben können.

Beispiel: Auto

Kurzfassung: Bauplan

Objekt

Ein konkretes Exemplar einer Klasse. Es besitzt eigene Werte für seine Attribute.

Beispiel: meinAuto

Kurzfassung: konkretes Ding

Attribut

Eine gespeicherte Eigenschaft oder ein Zustand eines Objekts.

Beispiel: farbe = "rot"

Kurzfassung: Eigenschaft/Zustand

Methode

Eine Aktion oder Fähigkeit, die ein Objekt ausführen kann.

Beispiel: fahren()

Kurzfassung: Aktion

    String farbe;
    int geschwindigkeit;
    void fahren() {
        System.out.println("Das Auto fährt.");
    }
}
