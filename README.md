# Unterrichtstools – Mathematik und Informatik
Willkommen in diesem Repository! Hier findest du verschiedene interaktive und webbasierte Unterrichtsmaterialien für die Fächer Mathematik und Informatik. Die Materialien bestehen aus HTML-Webseiten und können direkt im Browser geöffnet und genutzt werden. Sie dienen der Unterstützung des Unterrichts, der Veranschaulichung komplexer Themen sowie dem selbstständigen Lernen und Experimentieren.

## Verwendung
- Die Webseiten können ohne zusätzliche Installation verwendet werden.
- Repository herunterladen oder klonen.
- Gewünschte HTML-Datei auswählen.
- Die Datei mit einem beliebigen Browser öffnen.
- Die Anwendung direkt nutzen.
