# Unterrichtstools – Mathematik und Informatik
Willkommen in diesem Repository! Hier finden Sie verschiedene interaktive und webbasierte Unterrichtsmaterialien für die Fächer Mathematik und Informatik. Die Materialien bestehen aus HTML-Webseiten und können direkt im Browser geöffnet und genutzt werden. Eine zusätzliche Installation ist daher nicht nötig. Sie dienen der Unterstützung des Unterrichts, der Veranschaulichung komplexer Themen sowie dem selbstständigen Lernen und Experimentieren.

## Verwendung Extern
Hierbei sind die HTML-Dateien auf ihrem Gerät.
- Repository herunterladen oder klonen
- Gewünschte HTML-Datei auswählen
- Die Datei den Schülern beispielsweise über Moodle bereitstellen
- Mit einem beliebigen Browser öffnen

## Verwendung Intern
Hierbei bleiben die HTML-Dateien in diesem Repository. Der Vorteil besteht darin, dass stets die aktuellste Version verwendet wird.
- Gewünschte HTML-Datei auswählen
- Den `Pfad` der HTML-Datei kopieren
- Den Link `https://masterseyf.github.io/Unterricht/<Pfad>` den Schülern bereitstellen
- Mit einem beliebigen Browser öffnen
